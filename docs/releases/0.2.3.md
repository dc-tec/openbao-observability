# OpenBao Observability 0.2.3

OpenBao Observability 0.2.3 updates the Go toolchain to 1.27.3 to address
CVE-2026-111943, the eMudhra intermediate CA compromise.

## Security impact

Go 1.27.3 rejects certificate chains containing any of the eight compromised
public keys. The CLI uses system trust by default when it validates dashboard
queries against HTTPS Prometheus or Loki endpoints. Its OpenBao fixture
scenario client can also connect to an HTTPS address. These connections can
be affected even when the real endpoint does not use an eMudhra certificate.

Rebuild locally installed CLI binaries from the 0.2.3 source tag with Go
1.27.3 or later. Reload the development environment after updating the
checkout. The audit archive health exporter's builder also uses Go 1.27.3;
the exporter reads a local status file and serves HTTP, with no outbound TLS
client.

The release asset is a reference bundle of source examples and configuration.
It does not contain compiled CLI binaries or container images. Updating the
bundle does not patch OpenBao, Prometheus, Loki, Grafana, Grafana Alloy, or
other deployed clients. Assess and update those binaries separately where
they use public certificate trust. The default Compose profile uses HTTP
between its local services.

Certificates that chain through the compromised keys fail verification after
the Go update. Replace affected certificates with certificates from an
unaffected CA. Do not disable TLS verification to restore connectivity.

Read the [Go security advisory](https://github.com/golang/go/issues/82345) and
[Mozilla incident report](https://blog.mozilla.org/security/2026/10/20/protecting-firefox-users-following-the-compromise-of-emudhra-intermediate-certificates/).

## Dependency and profile updates

This release also includes the dependency updates already merged after 0.2.2:

- OpenBao API client 2.7.1 and Prometheus client 1.25.0. Dashboard validation
  accepts the Prometheus client's additional result while preserving query
  warnings and errors.
- Prometheus Common 0.72.0, Prometheus 0.315.0, and `golang.org/x/net` 0.60.0.
- Default Compose images for OpenBao 2.7.1, Prometheus 3.15.0, Grafana Alloy
  1.20.1, and Grafana 13.2.3. Loki remains at 3.7.8.

These image versions do not establish that their binaries contain the Go
1.27.3 certificate rejection update.

## Compatibility and validation

The release does not change contracts, generated rules, dashboards, or scrape
configuration. CI captures fresh OpenBao 2.6.3 and 2.7.0 fixtures and verifies
them independently. The release workflow repeats fixture capture and full
repository verification before packaging the release assets.

## Release assets

- `openbao-observability_0.2.3.tar.gz`: reference artifact bundle.
- `checksums.txt`: SHA256 checksums for release assets.
